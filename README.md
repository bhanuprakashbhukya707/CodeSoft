# 📝 To-Do List Application

## 📌 Task 1 – CodeSoft Internship

A simple command-line To-Do List application developed using Python. This project helps users create, view, and manage their daily tasks through an easy-to-use menu-driven interface.

---

## 🎯 Objective

The objective of this project is to develop a To-Do List application using Python that allows users to manage their tasks efficiently.

The application provides options to:

- Add new tasks
- View existing tasks
- Complete tasks
- Delete tasks
- Exit the application

---

## ✨ Features

### 1. Add Task
Users can enter a new task, which is added to the To-Do List.

### 2. View Tasks
Users can view all the tasks currently available in the list.

### 3. Complete Task
Users can select a task and mark it as completed.

### 4. Delete Task
Users can select a task and remove it from the list.

### 5. Exit
Users can safely exit the application.

---

## 🛠️ Technologies Used

- *Programming Language:* Python
- *Interface:* Command Line Interface (CLI)
- *Concepts Used:*
  - Lists
  - Loops
  - Conditional statements
  - Functions
  - User input
  - Basic error handling

---

## ⚙️ How It Works

1. The program starts by displaying the To-Do List menu.
2. The user selects an option from the menu.
3. If the user selects *Add Task*, they can enter a new task.
4. If the user selects *View Tasks*, all saved tasks are displayed.
5. If the user selects *Complete Task*, the selected task is marked as completed.
6. If the user selects *Delete Task*, the selected task is removed.
7. The menu continues to appear until the user chooses *Exit*.
